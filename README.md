<details>
<summary>⚙️ How this snake is generated (click to expand)</summary>

<br/>

This animation is generated automatically by <a href="https://github.com/Platane/snk">Platane/snk</a>, a GitHub Action that turns your contribution graph into a snake eating your commits. To set it up on your own profile repo:

1. Create the file `.github/workflows/snake.yml` with the content below.
2. Push it to your **profile repository** (the one named exactly like your username).
3. The action will run on a schedule and publish the generated SVGs to an `output` branch.

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *" # runs once a day
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: LucasB322
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>
